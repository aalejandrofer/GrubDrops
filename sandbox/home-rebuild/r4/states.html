Set up GrubDrops

Three steps. After that it runs on its own.

  1. 1

    Add an account

    Sign in with the account that should earn the drops. You can add more later in Settings.

    Add Twitch account Add Kick account
  2. 2

    Pick your games

    Search for a game. Top of the list mines first; reorder it on Games.

    • RustCampaign live now
    • Marvel RivalsCampaign live now
    • OverwatchNo campaign right now. We'll watch for one.
    • Dead by DaylightNo campaign right now. We'll watch for one.
    • DDeadlockNo campaign live
  3. 3

    Done

    GrubDrops mines only those games and claims each drop for you. This page then shows what's mining.

How it works

  • 1
    Watches for you. Each account watches one live stream of a game you picked.
  • 2
    Claims for you. When a drop's time is reached, it's claimed right away.
  • 3
    Keeps looking. New campaigns are checked every 5 min.
